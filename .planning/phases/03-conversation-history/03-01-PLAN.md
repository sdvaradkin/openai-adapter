    1. Install dependencies:
       - `npm install ioredis`
       - `npm install --save-dev @testcontainers/redis`

    2. Extend `src/config/types.ts` — add three new fields to the existing AdapterConfig interface:
       - `redisUrl: string` — Redis connection URL
       - `redisKeyPrefix: string` — key namespace prefix (default: `oai-adapter:`)
       - `conversationTtlSeconds: number` — TTL for stored turns (default: 86400 = 24h)
       - `conversationMaxDepth: number` — max chain walk depth (default: 75)

    3. Extend `src/config/loader.ts`:
       - Add `REDIS_URL` to the EnvConfig interface as required string
       - Add `REDIS_URL` to the env-schema `schema` object with `type: 'string', minLength: 1` (required — env-schema throws if missing)
       - Add optional `REDIS_KEY_PREFIX` string to schema
       - Add optional `CONVERSATION_TTL_SECONDS` string to schema
       - Add optional `CONVERSATION_MAX_DEPTH` string to schema
       - In `loadConfiguration()`, parse the new env vars using existing `parseIntegerEnvVar` for TTL and depth, use string directly for URL and prefix
       - Include the four new fields in the returned AdapterConfig object
       - Default values: prefix = `'oai-adapter:'`, TTL = 86400, depth = 75

    4. Create `src/history/types.ts`:
       ```typescript
       export interface StoredTurn {
         userInput: string;
         assistantOutput: string;
         previousResponseId: string | null;
       }
       ```

    5. Create `src/history/redis-client.ts`:
       - Export `createRedisClient(redisUrl: string): Redis` factory function
       - Use ioredis with options: `lazyConnect: true`, `enableOfflineQueue: false`, `maxRetriesPerRequest: 1`
       - Add `retryStrategy` that stops after 3 attempts (return null)
       - Add `error` event listener that logs warning via `console.warn(JSON.stringify({ level: 'warn', msg: 'Redis connection error', error: err.message }))` — do NOT crash
       - Return the Redis instance (caller connects lazily on first command)

    6. Create `src/history/conversation-store.ts`:
       - Import `Redis` type from `ioredis`, import `StoredTurn` from `./types.js`
       - Export `storeTurn(redis: Redis, responseId: string, turn: StoredTurn, keyPrefix: string, ttlSeconds: number): Promise<void>`
         - Build key as `${keyPrefix}${responseId}`
         - Call `await redis.set(key, JSON.stringify(turn), 'EX', ttlSeconds)`
         - Wrap in try/catch — on error, log warning via `console.warn(JSON.stringify({ level: 'warn', msg: 'Failed to store conversation turn', responseId, error: String(err) }))` and return (do not throw)
       - Export `reconstructMessages(redis: Redis, startResponseId: string, keyPrefix: string, maxDepth: number): Promise<Array<{ role: string; content: string }>>`
         - Iterative while-loop (NOT recursive): start from startResponseId, walk previousResponseId chain
         - Collect turns in an array (newest first), then reverse for chronological order
         - On missing key (redis.get returns null): break loop — use partial history from that point forward
         - On Redis error (catch): break loop — use partial history
         - Cap at maxDepth iterations
         - Build messages[]: for each turn, push `{ role: 'user', content: turn.userInput }` then `{ role: 'assistant', content: turn.assistantOutput }`
         - Return the messages array (may be empty if no history found)

    All files must use `.js` extensions in import paths per project convention. Use JSDoc on all exported functions. Follow existing code style (single quotes, trailing commas, 100 char width).
